# Mujahid Rafiq — Portfolio

Modern, responsive personal site built with Vite, React, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Netlify

The repo includes `netlify.toml`. Connect the project in Netlify, or run:

```bash
npm run build
```

and publish the `dist` folder.
